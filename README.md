Project Description: My project is the culmination of the fake college Livingston College, which is hosting a featured event called LivinCODE-A-THON. 
The intended audience is for STEM students and faculty who go to Livingston College, and are looking to sharpen their skills, collaborate with others, with a small bonus of winning a prize.
------------------------------------------------------------------------------------------------------------------
Layout Decisions: Flexbox: I used flexbox to put the footer towards the bottom of the page.
                  I used Flexbox for the navigation header to align the title of the university and navigation menu while simultaneously separating them.
                  I used flexbox on the navigation links for the purpose of spacing them.
                  I used flexbox to put the footer towards the bottom of the page.
          Grid: I used Grid for the events on the front webpage. This put the wrapping around the events under the featured event.
----------------------------------------------------------------------------------------------------------
  Responsive Design: My breakpoints are towards the end of the code. For the tablet query, I made the max width:768px, with scaling down the padding of the event cards, and the font-size.
  For the mobile query, I made the max width:488px, used flex-direction: column for elements on the webpage to stack upon each other, and added a horizontal scroll container to the schedule table, which allows the content to be scrolled horizontally.
  I tested these pages using the mobile device chrome extension. I was able to see how the webpage will pop up on an iPhone 14, and iPad Air.
  -----------------------------------------------------------------------------------------------------------
  Semantic HTML: 
  Header: The <header> element, was used for the navigation bar, and school title. It was intended to show the content that viewers will first see when opening up the homepage.
  nav: The <nav> element, was used for the website links in the navigation bar.
  main: The <main> element, contains all the content that is relevant to the reader. The main includes the Coding-Hack-A-thon title and description, with a button that takes you to the event.
  Under it, are the five event cards that take place at the Student Center, and the about section that gives the reader a brief overview of
  the Livingston Student Center.
  time: The time element, shows the dates in a readable format for viewers. I used it in the Related/Upcoming events section that you will find on the featured event page.
